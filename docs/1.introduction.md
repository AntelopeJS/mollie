# Introduction

`@antelopejs/mollie` implements two interfaces on Mollie's API:

- `@antelopejs/interface-payment`: payments, hosted checkout, refunds, customers, saved methods and webhooks;
- `@antelopejs/interface-subscriptions`: natively, on Mollie's Subscriptions API, because Mollie fires every renewal itself.

There is no Mollie-specific interface. A backend that needs a Mollie feature the generic interfaces do not model calls Mollie directly.

## What it needs

Nothing but an API key. There is no Redis, database or API module dependency. Webhooks are verified by `VerifyWebhook`, which you call from your own route, so the module mounts no route of its own.

## Configuration

| Field        | Required | Meaning                                                                                 |
| ------------ | -------- | --------------------------------------------------------------------------------------- |
| `apiKey`     | Yes      | A Mollie API key, `test_…` or `live_…`                                                  |
| `webhookUrl` | No       | Your public webhook route; sent with every payment and subscription the module creates  |
| `accounts`   | No       | Further accounts, `{ name: { apiKey, webhookUrl } }`, chosen by the `provider` selector |
| `apiUrl`     | No       | The API base URL; `https://api.mollie.com` unless a test points it elsewhere            |

Mollie calls a webhook URL given per payment ("classic" webhooks). Without `webhookUrl`, Mollie calls nothing: payments still work and can be read with `GetPayment`, but no event is raised and no subscription renewal is reported.

## Identifiers

Every identifier is opaque to callers. Some are composites, because Mollie nests the record under another one:

| Record               | Identifier            | Why                                                              |
| -------------------- | --------------------- | ---------------------------------------------------------------- |
| Payment              | `tr_…`                | Mollie's own                                                     |
| Checkout session     | `tr_…`, the payment's | A Mollie payment is its own hosted page                          |
| Customer             | `cst_…`               | Mollie's own                                                     |
| Saved payment method | `cst_…:mdt_…`         | A mandate is read and revoked under its customer                 |
| Refund               | `tr_…:re_…`           | A refund is read under its payment                               |
| Subscription         | `cst_…:sub_…`         | A subscription is read, changed and cancelled under its customer |

An identifier of the wrong shape is reported as not found without asking Mollie.
