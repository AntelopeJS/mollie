`@antelopejs/mollie` implements two interfaces on Mollie's API:

- `@antelopejs/interface-payment` covers payments, hosted checkout, refunds, customers, saved methods and webhooks.
- `@antelopejs/interface-subscriptions` runs on Mollie's Subscriptions API, because Mollie creates every renewal payment itself.

There is no Mollie-specific interface. A backend that needs a Mollie feature that the two interfaces do not model calls Mollie directly.

## What it needs

The module needs only an API key. It depends on no Redis, database or API module. You call `VerifyWebhook` from your own route to verify webhooks, so the module mounts no route of its own.

## Configuration

| Field        | Required | Meaning                                                                                       |
| ------------ | -------- | --------------------------------------------------------------------------------------------- |
| `apiKey`     | Yes      | A Mollie API key, `test_…` or `live_…`                                                        |
| `webhookUrl` | No       | Your public webhook route. The module sends it with every payment and subscription it creates |
| `accounts`   | No       | Further accounts, `{ name: { apiKey, webhookUrl } }`, chosen by the `provider` argument       |
| `apiUrl`     | No       | The API base URL. It is `https://api.mollie.com` unless a test points it elsewhere            |

Mollie calls the webhook URL given with each payment. Mollie calls these "classic" webhooks. Without `webhookUrl`, Mollie calls nothing. Payments still work and `GetPayment` reads them, but the module raises no event and reports no subscription renewal.

A call that names a `provider` with no account under that name rejects with `PaymentError`, or `SubscriptionError` for a subscriptions function.

## Identifiers

Every identifier is opaque to callers. Some are composites, because Mollie nests the record under another one:

| Record               | Identifier            | Why                                                                 |
| -------------------- | --------------------- | ------------------------------------------------------------------- |
| Payment              | `tr_…`                | Mollie's own                                                        |
| Checkout session     | `tr_…`, the payment's | A Mollie payment is its own hosted page                             |
| Customer             | `cst_…`               | Mollie's own                                                        |
| Saved payment method | `cst_…:mdt_…`         | Mollie reads and revokes a mandate under its customer               |
| Refund               | `tr_…:re_…`           | Mollie reads a refund under its payment                             |
| Subscription         | `cst_…:sub_…`         | Mollie reads, changes and cancels a subscription under its customer |

The module reports an identifier of the wrong shape as not found, without asking Mollie.
